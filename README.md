# StatSphere

A single-page statistics learning experience with curated learning paths, interactive calculators, and a quick knowledge check.

## Getting started
Open `index.html` in your browser (or serve the folder with any static file server) to explore the site.

### Features
- **Learning paths** with previews for descriptive stats, probability, and inference.
- **Hands-on calculators** for mean/median, binomial probabilities, and confidence intervals.
- **Three-question quiz** to reinforce key ideas.
